# Personal Website

A static personal website for Boje Deforce, built to publish directly on GitHub Pages.

## Structure

- `index.html`: page content, project cards, experience, research, skills, contact links, and rotating role list.
- `styles.css`: layout, typography, responsive behavior, and color system.
- `assets/og-card.svg`: social sharing preview image.
- `.github/workflows/pages.yml`: GitHub Pages deployment workflow.

## Edit locally

Open `index.html` in a browser, or run a static file server from this directory.

Common edits:

- Replace `hello@example.com` with the real email.
- Replace GitHub and LinkedIn placeholder URLs.
- Update project cards with real links and measurable details.
- Add a resume PDF and update the Resume link.
- Add real publication links in the Research section.

## Publish on GitHub Pages

1. Create a GitHub repository for this folder.
2. Push the site to the `main` branch.
3. In GitHub, open **Settings > Pages**.
4. Set **Source** to **GitHub Actions**.
5. Push again, or run the **Deploy GitHub Pages** workflow manually.

GitHub will show the published URL after the workflow finishes.
